# СверкаСмет (SmartMatcher)

> **Программный комплекс интеллектуального аудита и сопоставления строительной сметной документации (ВОР и ЛСР)**  
> Разработано в рамках выпускной квалификационной работы (ВКР / дипломного проекта).

---

## 📌 О проекте

Сверка **Ведомостей объёмов работ (ВОР)** и **Локальных сметных расчётов (ЛСР)** — один из самых трудоемких процессов строительного контроля и экспертизы смет. Различия в формулировках расценок, несовпадение единиц измерения (например, `100 м²` против `м²`), обобщенные нормативные названия (например, расценка *«Прибор или аппарат»* вместо конкретного щита) и разночтения в объемах приводят к высокой вероятности ошибок при ручной проверке.

**SmartMatcher** решает эту задачу с помощью гибридного двухуровневого подхода:
1. **Уровень 1 (Детерминированный алгоритм v2)**:
   - нормализация строительного текста и извлечение физических параметров (сечения кабелей, диаметры труб, марки оборудования);
   - приведение строительных единиц к базовым физическим размерностям (`units.py`);
   - глобальная оптимизация сопоставления с защитой от порядка строк (порядок-независимый алгоритм);
   - выявление коллизий: конкуренция близких расценок, скрытые расхождения характеристик, скачки объёмов.
2. **Уровень 2 (ИИ-арбитраж сложных коллизий)**:
   - привлечение большой языковой модели (**Alice AI LLM Flash** / Yandex AI Studio) только для неочевидных и спорных позиций;
   - три стандартизированных решения арбитра: `CONFIRM` (подтвердить выбор алгоритма), `REASSIGN` (переназначить на точного кандидата), `REJECT` (отклонить всех кандидатов);
   - интеллектуальное локальное кэширование ответов (`results/llm_cache.json`) для минимизации расходов и нулевого ожидания при повторных запусках.
3. **Человек в контуре (Human-in-the-loop)**:
   - интерактивный веб-интерфейс инженера-сметчика для подтверждения или корректировки решений с возможностью выгрузки отчета в CSV.
4. **Научный бенчмарк и оценка качества**:
   - генератор контролируемых синтетических искажений (`perturb.py`);
   - расчет метрик качества сопоставления (Precision, Recall, F1-macro, точность выявления расхождений) в сравнении с классическим базовым алгоритмом (`baseline_legacy.py`).

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/gsaryann/sverka.git
cd sverka
```

### 2. Установка зависимостей
Требуется **Python 3.10** или выше (рекомендуется Python 3.12).

```bash
pip install -r requirements.txt
```

### 3. Запуск веб-приложения

#### На Windows:
Просто запустите файл **`start_web.bat`** (двойным кликом или из консоли):
```powershell
.\start_web.bat
```

#### На Linux / macOS:
```bash
python web/web_app.py
```

После запуска откройте в браузере: **`http://127.0.0.1:5000`**.

> 💡 **Важно**: Основной алгоритм **SmartMatcher работает полностью локально и офлайн** — для него **не нужны** API-ключи и интернет! Вы можете сразу загружать `.xlsx` файлы или тестировать встроенные комплекты.

---

## 🤖 Настройка режима с ИИ-арбитром (опционально)

Если вы хотите подключить ИИ-арбитраж коллизий через Yandex AI Studio:
1. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```
   *(или переименуйте вручную в проводнике)*
2. Укажите ваши ключи в файле `.env`:
   ```env
   YANDEX_API_KEY=ваш_ключ
   YANDEX_FOLDER_ID=ваш_folder_id
   YANDEX_MODEL=aliceai-llm-flash/latest
   ```

## 💻 Запуск через командную строку (CLI)

### Сопоставление произвольной пары файлов:
```bash
python run_compare.py "data/ВОР.xlsx" "data/ЛСР.xlsx" "results/мой_отчет.csv"
```
С добавлением ИИ-арбитра:
```bash
python run_compare.py "data/ВОР.xlsx" "data/ЛСР.xlsx" --llm
```

### Запуск экспериментов и сравнительного бенчмарка:
```bash
python run_baseline.py --compare "data/ВОР.xlsx" "data/ЛСР.xlsx"
```

### Запуск набора модульных тестов:
```bash
python -m unittest discover -v
```
*(Проект содержит 27 автоматических тестов логики единиц, парсеров, сопоставления и защит LLM-резолвера)*.

## 📂 Структура проекта

```text
sverka/
├── data/                    # Реальные парные комплекты сметной документации (.xlsx)
│   ├── ВОР.xlsx <-> ЛСР.xlsx                      (86 позиций)
│   ├── ВЕДОМОСТЬ ОБЪЕМОВ... <-> ЛОКАЛЬНЫЙ СМЕТНЫЙ... (83 позиции)
│   ├── ВОР (1 этаж кабинеты).xlsx                 (534 позиции)
│   └── ВОР освещение КОРР.xlsx                    (137 позиций)
├── web/                     # Веб-приложение (Flask + HTML5 / Modern CSS / Vanilla JS)
│   ├── web_app.py           # Backend сервер и REST API
│   ├── index.html           # Интерфейс сметчика и вкладка экспериментов ВКР
│   ├── app.js               # Клиентская логика интерактивного аудита
│   └── style.css            # Стили оформления
├── results/                 # Результаты расчетов и локальный кэш
│   └── llm_cache.json       # Кэш ответов ИИ-арбитра (экономит баланс API)
├── match.py                 # Алгоритмическое ядро сопоставления SmartMatcher v2
├── parsers.py               # Извлечение данных из Excel, характеристик и нормализация
├── units.py                 # Нормализация единиц измерения и коэффициентов пересчета
├── llm_resolver.py          # Клиент Yandex AI Studio, промпты арбитража и кэширование
├── baseline_legacy.py       # Базовый алгоритм для сравнительного бенчмарка ВКР
├── perturb.py               # Генератор синтетических возмущений для стресс-тестов
├── evaluate.py              # Расчет метрик (Precision, Recall, F1, матрицы ошибок)
├── run_compare.py           # Скрипт CLI для сравнения документов
├── run_baseline.py          # Скрипт CLI для проведения экспериментов
├── test_suite.py            # Модульные тесты алгоритма и нормализации
├── test_llm_resolver.py     # Модульные тесты защит вокруг LLM
├── start_web.bat            # Скрипт быстрого запуска для Windows
├── requirements.txt         # Список внешних зависимостей Python
├── .env.example             # Пример файла переменных окружения
└── .gitignore               # Исключение ключей и временных файлов из репозитория
```
