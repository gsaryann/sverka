## 5. Предлагаемая правка (текстом, без изменения кода продукта)

При нормализации поля `ref` перед поиском в справочнике ФСНБ-2022 вместо простого удаления всех пробелов (`re.sub(r"\s+", "", s).upper()`) следует выделять ведущий токен шифра регулярным выражением:

```python
m = re.match(
    r"^(ГЭСН[А-ЯЁ]*\s*\d{2}-\d{2}-\d{3}-\d{2}|ФСБЦ-\d{2}\.\d+\.\d{2}\.\d{2}-\d{4})",
    (ref or "").strip().upper(),
)
norm_ref = re.sub(r"\s+", "", m.group(1)) if m else ""
```
Это отсекает примечания («Применительно», «Сплит-форма ...», коэффициенты) без потери самого шифра.
