## Этап 1. Быстрые правки кода (Выполнен 14–16.11.2026)
- **Предупреждение о формулировках:** признак пары при сильном различии слов или назначении из другого раздела сметы.
- **Диапазоны параметров:** «5–40 мм» и «20–40 мм» корректно определяют расхождение характеристик.
- **Классификация «Дубль»:** отнесена к категории «Требует проверки».
- **Парсер формул:** сметные объёмы, записанные формулами в ячейках Excel («=12.5*4»), читаются штатно без потерь строк.
- **Тесты:** подтверждён эталон по шифрам для пары «Приложение №2.3» (23 из 23).

## Этап 2. Новые функции и финансовый риск (Выполнен 22–23.11.2026)
*Закрыты рекомендации преподавателя по практике и научного руководителя:*
- **Оценка финансового риска расхождений:** реализован точный расчёт по формуле $|V_{\text{ЛСР}} - V_{\text{ВОР}}| \times P_{\text{ед}}$ на базе расценок ЛСР (колонки 14, 16, 12). Мок-формулы полностью устранены.
- **Официальный Акт разногласий в Excel:** генерация защищённого .xlsx по сметным стандартам с реквизитами объекта, формулами суммирования риска и блоками подписей Заказчика и Подрядчика.
- **Локальный офлайн-режим (SmartMatcher Core v2):** детерминированное сопоставление работает строго локально без отправки смет во внешние сервисы.
- **Нормализация единиц:** пересчёт стандартных сметных масштабов (10, 100, 1000, 10000) с автоматической проверкой эквивалентности.
- **Нормативная база (ФСНБ/ГЭСН):** проведена разведка; машиночитаемый открытый API отсутствует, в работе описан как перспективный модуль интеграции.

## Этап 4. Интерфейс, эргономика и публикация (Выполнен 23.11.2026)
- **Компактный 2-строчный терминал:** чистое отображение статусов, индикатора финансового риска и быстрых фильтров.
- **Аппаратный клавиатурный конвейер:** разбор коллизий клавишами Y (принять), N (в правку), Z (отмена) без использования мыши.
- **Автоскрытие пустого инспектора:** при пустой таблице правая панель автоматически скрывается, исключая пустые рамки на экране.
- **Умный стек модальных окон:** при ошибке парсинга окно выбора файлов остаётся открытым, позволяя сразу заменить файл.
- **Интерактивный онбординг (7 шагов):** наполнение живыми демонстрационными данными (таблица, инспектор, карточки примеров) — никакого белого экрана.
- **Устранение «B2B SaaS» и «421/пр» из шапок:** лаконичный академичный брендинг «СверкаСмет» без лишней бюрократии.
- **База данных и сессионная авторизация:** PostgreSQL 17 / SQLite с сохранением истории и решений сметчика.
- **Бесшовная навигация:** переход между терминалом и главной страницей, единая кнопка входа.
